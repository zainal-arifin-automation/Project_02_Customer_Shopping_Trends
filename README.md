# Project 02 — Customer Shopping Trends

## Project Overview

This project analyzes customer shopping behavior using Python and Pandas.

The objective is to identify purchasing patterns, customer segments, product performance, and business opportunities from customer shopping data.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Analysis Performed

The analysis covers:

- Data loading and exploration
- Data cleaning and preparation
- Customer purchasing behavior analysis
- Product performance analysis
- Customer segmentation
- Purchasing pattern analysis
- Data visualization
- Business insights and recommendations

## Key Insights

The analysis is designed to identify:

- Customer purchasing patterns
- High-performing products
- Customer segments and their characteristics
- Purchasing preferences
- Opportunities to improve customer engagement and sales performance

## Business Value

The insights from this analysis can support business decision-making in areas such as:

- Customer segmentation
- Product strategy
- Marketing optimization
- Sales performance improvement
- Customer retention
